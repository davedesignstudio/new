# Bville Pizza & Grill

Marketing site for **Bville Pizza & Grill**, 159 Morristown Rd, Bernardsville, NJ.

## Run locally

```bash
cd bville-pizza
python3 -m http.server 8080
```

Open http://localhost:8080

## Contents

- `index.html` — landing page
- `styles.css` / `script.js` — layout, motion
- `images/` — logo plus guest photos from public restaurant listings
