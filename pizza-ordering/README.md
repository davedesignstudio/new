# Antica Pizzeria Napoletana — SolidJS Ordering UI

A Napoli-inspired pizza ordering interface built with [SolidJS](https://www.solidjs.com/), styled with Italian Renaissance art, architecture, and authentic Neapolitan pizzeria aesthetics.

## Features

- **Renaissance-inspired design** — Cinzel & Cormorant Garamond typography, gold ornamentation, fresco color palette, architectural arches and columns
- **Authentic Napoli menu** — Margherita, Marinara, Bufala DOP, Diavola, Quattro Stagioni, and more
- **Italian categories** — Pizze, Antipasti, Secondi, Contorni, Dolci, Bevande
- **Pizza builder** — Customize size, impasto, salsa, formaggio, and condimenti
- **Consegna / Asporto** order types with address input
- **Shopping cart** with IVA calculation and euro pricing
- **Responsive design** for mobile and desktop

## Getting Started

```bash
cd pizza-ordering
npm install
npm run dev
```

Open http://localhost:5173 in your browser.

## Build

```bash
npm run build
npm run preview
```

## Tech Stack

- SolidJS 1.x
- Vite 8.x
- Custom CSS (Renaissance & Napoli theme)

## Design Inspiration

- Neapolitan pizzeria websites (Via dei Tribunali aesthetic)
- Italian Renaissance art — fresco palettes, gilded accents, classical ornamentation
- Italian architecture — columns, arches, cornices, medallion frames
