# Fonts

Self-hosted variable web fonts (latin subset), both released under the
SIL Open Font License 1.1 (https://openfontlicense.org):

- Fraunces — display serif. https://github.com/undercasetype/Fraunces
- DM Sans — text sans. https://github.com/googlefonts/dm-fonts

`gulp fonts` copies everything in this directory to `dist/fonts/`.
