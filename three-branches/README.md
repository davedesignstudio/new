# The Three Branches of Government

A standalone, dependency-free educational website about the three branches of the
United States federal government: legislative, executive, and judicial.

## Features

- Overview of each branch with key facts and powers (Articles I–III)
- Interactive Checks & Balances explorer — pick a branch to see how it limits the other two
- Five-question knowledge quiz with instant feedback and scoring
- Responsive layout, no build step, no external dependencies

## Running locally

Serve the folder with any static file server, for example:

```bash
cd three-branches
python3 -m http.server 8080
```

Then open http://localhost:8080/.
