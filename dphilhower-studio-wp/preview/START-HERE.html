HTML, CSS, and JS bundle

This zip is the D Philhower Studio site as static files for dphilhower.com — no WordPress required. Open index.html to view the site.

What’s inside

All site pages as .html, one stylesheet css/main.css, and one script js/main.js. Images live in img/ so the pages render. See files.html for the full list.

Open on your computer

Unzip this folder, then double-click index.html. Or from this folder run python3 -m http.server 3000 and visit http://localhost:3000

Upload to dphilhower.com

Upload the contents of this folder (not the zip itself) into public_html at your host. Point the domain dphilhower.com at that hosting account. index.html is the homepage.
