# The Room Method
### An original graphic + web design process
Built for hospitality brands and studio work — informed by Double Diamond, design thinking, identity practice (Airey), and William Golden’s reduction.

---

## What I studied

| Source | What I took |
| --- | --- |
| **Double Diamond** (Design Council) | Diverge → converge twice: find the right problem, then the right solution |
| **Design thinking** (d.school) | Empathize → Define → Ideate → Prototype → Test (loop, don’t march) |
| **Graphic identity practice** (briefs, LucidLink / Airey) | Research → strategy → design → implementation; test the mark on real surfaces |
| **William Golden** (CBS Eye) | One idea. Geometry. Negative space. Scales from screen to sign. Cut everything else |
| **This studio’s hospitality habit** | The first conversation is at the table — not in a deck |

I did not copy a framework wholesale. I fused them into one path that fits restaurants, print, and the web as **one system**.

---

## The Room Method — 6 stages

```
SIT → SAY → SCATTER → SHEAR → STAGE → SHIP
 │      │       │         │        │       │
discover define  diverge   reduce  prototype deliver
```

### 1. Sit — be in the problem
**Graphic:** Who holds this? Who sees it from the sidewalk?  
**Web:** Who taps this first? What do they need before they order?  
**Do:** Meal / walkthrough / stakeholder talk. Capture facts, not moods.  
**Exit:** Raw notes + constraints (budget, surfaces, tech).

### 2. Say — write the problem in one line
**Graphic:** The sentence the window must say.  
**Web:** The job the homepage must finish.  
**Do:** Cut competitors. Name what we will *not* design.  
**Exit:** One-line brief + success test (“reads at dusk”, “orders in 3 taps”).

### 3. Scatter — many answers, no favorites
**Graphic:** 20 thumbnails. Wordmarks, symbols, seals.  
**Web:** 3 IA sketches + 2 layout directions.  
**Do:** Quantity first. No polishing.  
**Exit:** A shortlist of 3 directions max.

### 4. Shear — Golden’s cut
**Graphic:** Reduce to geometry. One idea. One color must work. Favicon *and* window.  
**Web:** Strip chrome. One primary action. Type scale that holds.  
**Do:** Kill decoration that doesn’t carry meaning.  
**Exit:** Locked mark + type + color (or wire core for web).

### 5. Stage — prove it on real holds
**Graphic:** Menu, window, pack, card, phone — same system.  
**Web:** Home → case → contact on real devices.  
**Do:** If it breaks on a coaster or a 375px screen, it isn’t done.  
**Exit:** Applied kit + responsive preview.

### 6. Ship — hand off and listen
**Graphic:** Print files, guidelines, naming.  
**Web:** Static/theme build, a11y check, live URL.  
**Do:** Collect holding feedback; loop to Shear or Stage — not to Sit unless the room changed.  
**Exit:** Live system + notes for the next pass.

---

## Rules (non-negotiable)

1. **Room before render** — Never start in Figma/Illustrator/codegen without Sit + Say.  
2. **One system** — Print and web share mark, color, type; layouts differ, language doesn’t.  
3. **Shear hard** — If it needs a paragraph to explain the logo, cut again.  
4. **Stage on truth** — Test on glass, paper, and phone — not only on a moodboard.  
5. **Loops are allowed** — Stage can send you back to Shear; Ship feedback returns to Stage. Only a new room restarts Sit.

---

## How this differs from stock frameworks

- Double Diamond maps problem/solution; **Room Method maps hospitality surfaces** (table → glass → pack → screen).  
- Design thinking centers users; we center **guest + operator** in the same room.  
- Identity books often stop at guidelines; we **Stage** before Ship so the kit survives printers and phone thumbs.  
- Golden’s reduction is not a style preference — it’s **stage 4**, required before anything goes public.

## Quick use on a logo (example)

| Stage | Brick & Basil / Midnight Noodle |
| --- | --- |
| Sit | Night bowl / wood-fired room — what must read at small size? |
| Say | “One geometric mark that means the room.” |
| Scatter | Badge, oven, leaf, bowl, moon… |
| Shear | Concentric rings + leaf pupil / eye-bowl + crescent |
| Stage | Black-only mark, Didot type, white ground |
| Ship | PNG artifacts + process locked for kit build |
