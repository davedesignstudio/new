Research

Design from 1950 to now

Labeled shelves. Parallel streams — not a civilizational ladder. A studio survey of graphic, identity, industrial, interface, and liberation print craft.

Shelf A · 1950–1970

Order as craft

  • Swiss / International — grid, Helvetica/Univers, photography, objective tone. Gave modular corporate layout; claimed neutrality is political.
  • Mid-century objects — Eames, Braun/Rams, Scandinavian warmth. Form follows function for daily use.
  • Corporate identity — Rand, Bass, Aicher: logo becomes operating kit (stationery, fleet, film).
  • Liberation + tricontinental print — Emory Douglas, OSPAAAL: poster as weapon. Parallel shelf, not a rung below Swiss.

Shelf B · 1968–1990

Break the grid, keep the tools

  • Postmodern / New Wave — Weingart, Cranbrook, Carson: voice and collage; chaos without stakes is noise.
  • Desktop publishing — Macintosh, PostScript, Illustrator, Photoshop: paste-up → file; craft becomes system pressure-test.
  • Fashion as media — mark as wearable signal; ancestor of tee / van kits.

Shelf C · 1990–2010

Screen as substrate

  • Web → Web 2.0 — identity must reflow; responsive thinking begins.
  • Skeuomorphism → Flat — teach touch with material metaphors, then strip chrome; Flat 2.0 restores affordances.
  • Design systems — tokens and component libraries: Brand OS lineage.
  • Accessibility — WCAG as craft requirement, not polish.

Shelf D · 2010–now

Systems, motion, generation

  • Material + platform grammars — motion and elevation as shared language.
  • Variable type / adaptive logos — text systems that survive pixel and foil.
  • Afrofuturist craft — speculative, technical, ancestral, made — parallel shelf, no ladder.
  • GenUI — envelope contract before stream; Action + Item + Limit; front-load stakes; pressure-test ≠ polish.

  • Logo / poster / tee / van — identity as operating kit, not a lone mark.
