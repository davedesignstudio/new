Craft canon · cherry-picked

Best techniques, labeled.

Eight techniques chosen from the full canon and the 1950–now survey—combined where they reinforce each other, dropped where they only decorate. Incorporated under D Philhower Studio (dphilhowerstudio.com) and applied on the Service the Hills subdomain.

Identity · picked

Caps–script wordmark hierarchy

  • Caps serif — authority line (SERVICE / GILT / SMOKE).
  • Script lockup — human middle line (The Hills / Tap / Rail).
  • Small-caps tagline — service line under the mark.
  • Limit — share the text structure, not a decorative saw for every brand.

Systems · corporate identity shelf

Operating kit (logo → fleet)

  • Brand as kit: seal, stationery, signage, vehicle—Rand / Bass lineage.
  • One hierarchy survives every substrate.
  • Limit — kits must keep local voice; templates alone erase it.

Layout · Swiss / International

Modular order before ornament

  • Grid, photography, clear type hierarchy as default information craft.
  • Use when a homeowner or client must find the next step fast.
  • Limit — “neutrality” is not universal; name the politics of the calm face.

Art · picked

Objecthood + parallel crafts

  • Marks and materials as objects—weight, join, use.
  • Afrofuturist craft welcome; no civilizational ladder.
  • Limit — parallel labeled shelves, never primitive→modern→future.

Craftsmanship · picked

Cooperage rive/saw; pressure ≠ polish

  • Match the tool to the stave—rive with the grain or saw across it.
  • Pressure-test the joint under load before surface shine.
  • Limit — polish without a stress-test is unfinished work.

Writing · picked

Plain ≠ meagre; Action + Item + Limit

  • Plain writing carries full meaning; short is not empty.
  • Status: Action + Item + Limit.
  • Example: Published Service the Hills subdomain · text system + kits · DNS still requires one-time host map.

GenUI / principles · picked

Envelope contract + stakes first

  • Name kind, scope, and constraints before content streams.
  • Front-load cost, risk, and legal edges—never stage them into Act III.
  • Break — if a mockup hides the hard part, the mockup is wrong.

Canons · picked

Labeled shelves; hear + do

  • Matthew 7: apply the brief—hearing without doing is unfinished craft.
  • Keep traditions on labeled shelves (Meqabyan ≠ Maccabees).
  • Limit — accuracy of citation and practice, not brand cosplay.
