Craft canon

Design techniques

Labeled shelves. Plain speech. Pressure before polish. This is how the studio builds marks, pages, and systems.

Design techniques

GenUI envelope contract + partial-safe streaming

  • Envelope contract — each generated chunk names its kind, its scope, and what it must not invent before content streams.
  • Partial-safe streaming — incomplete replies stay usable; status reads as Action + Item + Limit.
  • Limit — stream stakes and constraints first; polish last.

Principles / breaks

Front-load stakes; never stage away danger/legal

  • Put risk, cost, liability, and legal edges in the first pass — not Act III.
  • Do not soften danger with euphemism, decorative delay, or “we’ll handle that later.”
  • Break — if a mockup hides the hard part, the mockup is wrong.

Art

Objecthood + Afrofuturist craft; no civilizational ladder

  • Marks and materials are objects — weight, join, use — not flat decoration.
  • Afrofuturist craft: speculative, technical, ancestral, made.
  • Limit — no primitive→modern→future ladder. Parallel crafts on labeled shelves.

Writing

Plain ≠ meagre; Action + Item + Limit

  • Plain writing carries full meaning. Short is not empty.
  • Status format: Action (what moved) + Item (what it touched) + Limit (what it does not claim).
  • Example: Updated work index · three identity kits · case studies only; no pricing.

Jesus / Bible / canons

Mt 7 hear+do; shelves labeled

  • Matthew 7: hearing without doing is unfinished craft — apply the brief; don’t only quote it.
  • Keep canons on labeled shelves: Meqabyan ≠ Maccabees. Do not collapse names or traditions.
  • Limit — accuracy of citation and practice, not brand cosplay.

Craftsmanship

Cooperage rive/saw logic; pressure-test ≠ polish

  • Some work is riven with the grain; some is sawn across it. Match the tool to the stave.
  • Pressure-test the joint under load before polishing the surface.
  • Limit — shine without a stress-test is unfinished work.
