# Domino's Pizza Ordering UI (SolidJS)

A Domino's-inspired pizza ordering interface built with [SolidJS](https://www.solidjs.com/) and Vite.

## Features

- **Domino's-style branding** — Red and blue color scheme, familiar layout
- **Menu browsing** — Categories: Pizza, Sides, Wings, Sandwiches, Pasta, Desserts, Drinks
- **Pizza builder** — Customize size, crust, sauce, cheese, and toppings
- **Shopping cart** — Add/remove items, adjust quantities, apply coupons
- **Delivery / Carryout** — Toggle order type with delivery fee calculation
- **Checkout flow** — Order form with payment options and confirmation

## Getting Started

```bash
cd pizza-order
npm install
npm run dev
```

Open http://localhost:5173 in your browser.

## Build

```bash
npm run build
npm run preview
```

## Coupon Codes (Demo)

- `PIZZA50` — 50% off all pizzas
- `FREEDRINK` — Free 2-liter with order
- `WINGS10` — $10 off wings

## Tech Stack

- SolidJS
- Vite
- CSS (no framework)
