Most menus fail in the hand. Too many weights, too many boxes, too many things asking to be first. The guest is already tired. The page should not add work.

This system uses **proximity** so a course is a cluster, not a list that runs on. Descriptions sit against their dishes. The gap between sections is larger than the gap inside a section — the grouping is felt before it is read.

**Focal point** is reserved. One dish, one treatment, one reason to look twice. The rest of the card stays quiet so that choice can land. If everything is a special, nothing is.
