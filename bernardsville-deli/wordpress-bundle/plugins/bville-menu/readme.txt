Imports the Bville Pizza & Grill printed menu as WooCommerce products (SKU, prices, photos, variations).

== Installation (GoDaddy WordPress) ==

1. Install and activate WooCommerce.
2. Upload `bville-menu.zip` via Plugins → Add New → Upload, or copy this folder to `wp-content/plugins/bville-menu`.
3. Activate **Bville Menu for WooCommerce**.
4. Go to WooCommerce → Bville Menu.
5. Keep “Attach bundled product photos” checked → Import / update products.
6. WooCommerce → Settings → Payments: enable Stripe, Square, or PayPal.
7. Appearance → Themes: activate the **Bville** theme from this bundle.

== SKUs ==

`BVL-{SECTION}-{SLUG}` — pizzas are variable (12" / 16"). Wings use piece counts.
