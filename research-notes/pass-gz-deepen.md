## 1. Sole Archive mini catalog schema (vault cards)

Vault cards are **interaction containers** (KEEP: cards only for interaction). Schema fields:

| Field | Type | Role |
|-------|------|------|
| `sku` | string | Internal id, not Nike™ SKU paste into brand mark |
| `model` | string | Product line name as sold (e.g. Air Jordan 1 Retro High) |
| `year` | number | Release / this pair’s year |
| `condition` | enum | DS · VNDS · Used-graded |
| `authenticity` | enum | Verified · Pending · Independent (disclose) |
| `holdStatus` | enum | Open · Hold · Sold |
| `holdExpiry` | ISO datetime | **BREAK** progressive disclosure — show if Hold |
| `price` | money | Envelope (control) ≠ fill (product photo) |

**Degrees of freedom:** filters for year/condition stay in a drawer (KEEP progressive disclosure); hold expiry + authenticity stay above the fold on the card (BREAK).
