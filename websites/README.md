## Design joints (`shared/pattern.css`)

- Brand-first full-bleed heroes
- Fitts ≥48px primary CTAs
- `prefers-reduced-motion` cancels kinetic drift
- Stakes always above the fold
- Hold/Reserve microcopy = Action + Item + Limit
- Cards only for interaction
- Sole Archive logo = SA monogram (no Nike™ in mark)
