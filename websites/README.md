# Studio Five — research + creative delivery

Pass HA (Crosslink) deliverable: five logos, five illustrations, and five branded static sites sharing one pattern language.

## Brands

| Site | Type |
|------|------|
| [kiln-and-cup](./kiln-and-cup/) | Cafe |
| [mist-harbor](./mist-harbor/) | Cafe |
| [ember-court](./ember-court/) | Restaurant |
| [citrus-hull](./citrus-hull/) | Restaurant |
| [sole-archive](./sole-archive/) | Collectible sneaker vault (independent; Nike products as catalog objects) |

Open [index.html](./index.html) for the gallery, or:

```bash
cd websites && python3 -m http.server 8765
```

## Pattern language

`shared/pattern.css` crosslinks allergy/care **croze** checklists, Sole Archive **catalog schema**, and Didache **Two Ways** mercy stakes (Action · Item · Limit) across all five brands.
