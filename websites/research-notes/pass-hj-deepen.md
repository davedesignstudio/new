## Deepened thread — GenUI Pattern 2: Progressive Component Streaming
Source: Mantlr *Generative UI in 2026: 7 Design Patterns That Work* (Apr 2026).

1. **Stream the UI** — components appear as the agent commits; do not wait for a single final payload.
2. **Partial-data grace** — every component needs loading · partial · error · ready states by default.
3. **Chrome first** — render stable envelope (stakes, stream rail, nav, CTAs) immediately; stream only the fill band.
4. **Deterministic fallback** — if generative assembly fails, serve the static board; icing cannot be the cake.
5. **PRM covenant** — streaming shimmer / staggered reveal cancel under `prefers-reduced-motion` (instant ready).

Maps to Survey Pattern 4: **envelope = hoop; fill = stave that may stream.**
