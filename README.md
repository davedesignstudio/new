# Rasa

A restaurant site for **Rasa**, a dining house of Swedish stillness, Japanese craft, and Vedic fire. Built with [Victor Hugo](https://github.com/netlify/victor-hugo) (Hugo + Gulp + Webpack).

## Usage

```bash
npm install
npm run start
```

Visit http://localhost:3000/

```bash
npm run build
```

writes static files to `/dist`.
