# Philhower & Okrogly

Design-and-build studio site for **Philhower & Okrogly** — carpentry design and build, plus web design and branding. Official theme song: **Grain & Grid**.

## Run locally

```bash
nvm use
npm install
npm run start
```

Then open http://localhost:3000/

## Build

```bash
npm run build
```

Output is written to `/dist`.
