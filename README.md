# Philhower & O’Krogly — Design + Build

Northern New Jersey construction and design company specializing in **carpentry design and build**, plus **web design and branding**.

## Local development

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000). The site is static HTML/CSS/JS in `public/`.

## Pages

- `/` — Home
- `/services/` — Carpentry, construction, branding, web
- `/work/` — Lockup and print system
- `/theme-song/` — Official theme song “Design + Build” (lyrics + playable jingle)
- `/about/` — Company
- `/contact/` — Phone and inquiry

## Theme song

The company theme, **“Design + Build”**, lives at `/theme-song/`. Lyrics cover the dual craft (timber and pixels); the page includes a short Web Audio jingle.
