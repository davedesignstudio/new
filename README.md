# SolidJS Pizza Ordering UI

Domino's-inspired pizza ordering experience built with **SolidJS** and **Vite**.

## Features

- Delivery / Carryout order toggle
- Full-bleed hero with brand-first layout
- Featured deals
- Menu categories (Pizza, Chicken, Sides, Pasta, Sandwiches, Desserts, Drinks)
- Domino's-style pizza builder (size, crust, sauce, cheese, toppings)
- Cart with tax, delivery fee, and checkout summary

## Develop

```bash
npm install
npm run dev
```

Open the URL Vite prints (default `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Note

This is a UI demo inspired by Domino's ordering flow and visual language. It is not affiliated with Domino's Pizza.
