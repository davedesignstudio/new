# HOTBOX — SolidJS Pizza Ordering UI

Domino's-inspired online pizza ordering experience built with **SolidJS** and Vite.

## Features

- Delivery / Carryout order start
- Menu with Deals, Pizza, Sides, Drinks, Desserts
- Specialty pizzas + Build Your Own
- Step-based pizza builder (crust → size → sauce → cheese → toppings)
- Live visual pizza preview
- Cart drawer with tax / delivery fee
- Checkout + order confirmation tracker

## Run

```bash
npm install
npm run start
```

Open the local URL Vite prints (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Stack

- SolidJS
- TypeScript
- Vite
