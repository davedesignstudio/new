# Domino's-inspired Pizza Ordering UI (SolidJS)

Interactive pizza ordering experience built with **SolidJS** and **Vite**, modeled on Domino's online ordering flow.

## Features

- Delivery / Carryout toggle
- Category menu (Deals, Pizza, Sides, Desserts, Drinks)
- Full pizza builder (crust, size, sauce, cheese, toppings)
- Cart drawer with tax & delivery fee
- Pizza Tracker®-style status strip
- Responsive layout with Domino's red/blue branding

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Stack

- SolidJS
- TypeScript
- Vite
- CSS (no UI framework)
