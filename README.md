# Philhower & O’Krogly — Design + Build

Northern New Jersey construction and design company specializing in **carpentry design and build** as well as **web design and branding**.

## Theme song

Official company theme: **“Design + Build”**

- Full lyrics and playable browser jingle: `/theme-song/`
- Chorus: *Philhower & O’Krogly — Design + Build, from curb to screen.*

## Local development

```bash
npm run start
```

Visit http://localhost:3000/

## Build

```bash
npm run build
```

Static site source lives in `public/`. Build copies to `dist/` for Netlify.
