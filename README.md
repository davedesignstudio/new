# PieDash — SolidJS Pizza Ordering UI

Domino's-inspired pizza ordering experience built with **SolidJS** + Vite.

## Features

- Delivery / Carryout order start (Domino's-style gate)
- Sticky header with order type chip and live cart total
- Featured deals rail
- Specialty pizza menu with live SVG pizza previews
- **Build Your Own** builder: crust, size, seasoning, sauce, cheese, meats, veggies, dips
- Running price summary and add-to-order cart
- Sides, chicken, desserts, and drinks
- Responsive layout for desktop and mobile

## Run

```bash
npm install
npm run dev
```

Open the printed local URL (default `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Note

PieDash is a demo UI inspired by Domino's ordering patterns. It is not affiliated with Domino's Pizza.
