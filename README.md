# Nino's Pizza — SolidJS Ordering UI

Domino's-inspired pizza ordering experience built with **SolidJS** + Vite.

## Features

- Delivery / Carryout service toggle
- Specialty pizza menu with live images
- Full pizza builder (crust, size, sauce, cheese, meats, veggies)
- Sides, drinks, and desserts
- Cart drawer with tax + delivery fee
- Place-order confirmation toast

## Scripts

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run preview
```

## Stack

- SolidJS 1.9
- Vite 8
- TypeScript
