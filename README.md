# The Three Branches

A civic explainer of how the United States Constitution divides federal power among Congress, the President, and the courts. Built on the Victor Hugo (Hugo + Gulp + webpack) starter.

## Pages

- Overview — separation of powers and a short “which branch?” quiz
- Legislative — Article I, the House and Senate
- Executive — Article II, the presidency and the agencies
- Judicial — Article III, the federal courts and judicial review
- Checks & Balances — how the branches restrain one another

## Usage

```bash
npm install
npm run start
```

Visit http://localhost:3000/

```bash
npm run build
```

Static output is written to `dist/`.
