# D. Philhower Studio

Starter website layout from a studio drawing: a two-column frame with vertical service labels, a skateboard wordmark, a featured video, right-side navigation, and social marks.

## Usage

```bash
npm install
npm run start
```

Then visit http://localhost:3000/

```bash
npm run build
```

Static output lands in `/dist`.
