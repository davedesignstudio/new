# D Philhower Studio

Homepage layout based on the studio sketch: left vertical service rail (Web Design / Print / Advertising + Marketing), brand lockup with skate mark, Home · Work · call us · Social, and a featured video stage.

## Local development

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000). Static files live in `public/`.

## Pages

- `/` — Sketch layout (home)
- `/work/` — Selected work
- `/contact/` — Call us / inquiry form

## Deploy

Netlify publish directory: `public` (see `netlify.toml`).
