# Philhower & Okrogly

Construction and design company site for **Philhower & Okrogly** — carpentry design-build, web design, and branding.

Theme song: **Grain & Grid** (play it at `/theme-song`).

## Run locally

```bash
npm install
npm start
```

Visit http://localhost:3000/

```bash
npm run build
```

writes static files to `/dist`.

## Theme song

The instrumental is generated by `scripts/generate-theme-song.py`, then encoded:

```bash
python3 scripts/generate-theme-song.py
ffmpeg -y -i site/static/audio/grain-and-grid.wav -codec:a libmp3lame -b:a 192k site/static/audio/grain-and-grid.mp3
ffmpeg -y -i site/static/audio/grain-and-grid.wav -c:a libvorbis -qscale:a 5 site/static/audio/grain-and-grid.ogg
rm site/static/audio/grain-and-grid.wav
```
