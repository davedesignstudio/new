# Dilhower Studio

Layout start for **Dilhower Studio**, built from the skate-culture homepage sketch: left service rail, center video shard, right-hand brand lockup.

## Local development

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000). The site is static HTML/CSS/JS in `public/`.

## Pages

- `/` — Home (layout from the drawing)
- `/work/` — Web, print, and advertising placeholders
- `/contact/` — Call us

## Deploy

Netlify publish directory: `public`.
