# D Philhower Studio

Homepage layout for [D Philhower Studio](https://dphilhowerstudio.com), built from a hand-drawn sketch: left-side service rails, a skate lockup, Home / Work / call us, and a hero video stage.

## Run locally

```bash
npm install
npm run start
```

Then visit http://localhost:3000/

## Build

```bash
npm run build
```

Static output lands in `/dist`.
